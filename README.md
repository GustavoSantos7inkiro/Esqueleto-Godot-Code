# Esqueleto Infernal
GDScript source code from a game developed with Godot Engine.


# Apresentação

Repositório destinado à apresentação dos scripts de programação desenvolvidos por mim para um jogo criado com a Godot Engine.


## Sobre o projeto

Este projeto foi desenvolvido utilizando Godot Engine e GDScript.

O repositório contém somente os scripts criados por mim. Artes, músicas, efeitos sonoros, fontes e outros recursos de terceiros não foram incluídos, pois pertencem aos seus respectivos autores e possuem licenças próprias.

Por esse motivo, esta versão é destinada à demonstração de código e não representa o projeto completo executável.


## Tecnologias

- Godot Engine
- GDScript

## Minha contribuição

- Programação das mecânicas de gameplay
- Implementação da movimentação do personagem
- Programação dos inimigos
- Controle dos estados e progressão do jogo
- Implementação da interface
- Testes e correção de erros

## Estrutura

Os códigos desenvolvidos para o projeto estão disponíveis na pasta:

`/scripts`


## Observação

Os recursos gráficos, sonoros e demais assets não estão incluídos neste repositório.
